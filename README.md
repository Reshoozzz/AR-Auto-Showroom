## Project Description
An Augmented Reality Auto Showroom built using Unity. The app supports markerless AR placement, marker-based image tracking, vehicle customization, animations, audio, and user interactions.

## Main Features
- Markerless plane detection
- Marker-based image tracking
- Vehicle selection
- Vehicle color customization
- Wheel customization
- Door animations
- Engine sound
- Voiceover playback
- Touch gestures: tap, drag, pinch
- Performance report
